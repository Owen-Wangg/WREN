Installation

Copy the steering files into your project:

cp *.md /path/to/your-project/.kiro/steering/

Or clone from the boilerplate and add your UBC CIC files:

cd your-project && mkdir -p .kiro/steering && cp /path/to/ubc-cic-*.md .kiro/steering/

Inclusion Modes

always — Loaded in every Kiro interaction. Use for universal standards (Git, Security, Production Safety).

fileMatch — Loaded only when editing files matching the pattern. Use for language/framework specific rules.

auto — Loaded when Kiro determines the request matches the description. Use for specialized workflow patterns.

manual — Available on demand via #filename in chat. Use for troubleshooting or migration guides.
